## What it is

This Python program allows users to input a binary number and a decimal number, adds them together, and returns the sum in binary.

## What It Does

Takes two numbers as input, separated by a space:

The first is assumed to be a binary number (like 1010)

The second is a decimal number (like 3)

Converts the binary number to decimal

Adds the two decimal numbers

Converts the result back to binary

Prints the binary result of the sum

## How It Works

valor(numero) – (Not currently used) Designed to check if a number is binary.

binario(numero) – Converts binary string to a decimal integer.

decimal(numero) – Converts a decimal integer to a binary string.

The script parses the user's input, performs the conversion and calculation, and prints the final binary sum.
